# Traing the CVAE that is SubCellSpace.

To reproduce the training of the CVAE, simulated training data is needed. This can be simulated yourself by following the scripts in [create_simulations](./create_simulations/), or can be downloaded from zenodo.

The training is then done by following the [train_cvae](././train_cvae.py) script, after first creating the necessary environment using the [train_cvae.yml file](../yamls/train_cvae.yml)
