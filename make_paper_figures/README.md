# Reproducing the figures.

To reproduce the figures, use the yaml to create a conda environment of [analysis_figures.yaml](../yamls/analysis_figures.yml)

All notebooks work standalone, the only thing necessary besides a notebook and the *conda_env* is processed data, which can be found on [zenodo:10.5281/zenodo.19708995](19708995).   

If wanting to make use of the interactive features of SubCellSpace (e.g.: clicking on observations in the latent space and plotting them, drawing your own patterns...), jupyter nbclassic is prefered. Technically modern jupyterlab interactive modes should work, but I've had bad experiences with them.
